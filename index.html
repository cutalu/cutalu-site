Installation

  1. Téléchargez CutaluPro-Setup-0.9.3.exe.
  2. Ouvrez le fichier. Si Windows affiche « Windows a protégé votre ordinateur », cliquez sur Informations complémentaires, puis sur Exécuter quand même. Ce message s'affiche pour les logiciels récents qui ne sont pas encore signés numériquement.
  3. Suivez l'installation, puis ouvrez Cutalu Pro depuis le menu Démarrer.
